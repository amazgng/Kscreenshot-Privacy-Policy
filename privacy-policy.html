Kscreenshot Privacy Policy

Last updated: September 7, 2026

English简体中文

English

Kscreenshot is a Chrome extension for user-initiated webpage capture, screenshot editing, local capture history, and image/PDF export. This policy explains what information the extension processes, why it is needed, where it is stored, and how users can remove it.

1. Information Kscreenshot processes

  • Website content: visible webpage content such as text, images, page layout, links, and rendered visual content needed to create a screenshot or PDF.
  • Webpage metadata: the title and URL of a page you explicitly capture. These may be used in local history entries, filenames, PDF metadata, headers, or footers.
  • User-created capture data: screenshots, edited images, annotations, PDFs, and related local history records.
  • Extension preferences: settings such as interface language, image format, quality, filename prefix, PDF layout options, and post-capture behavior.

2. How this information is used

Kscreenshot uses this information only to provide its core functions: capturing webpages, selecting page areas or elements, editing screenshots, saving capture history, copying images to the clipboard, printing, and exporting image/PDF files.

3. Local storage and Chrome Sync

Screenshot history and capture files are stored locally in the browser using extension storage such as IndexedDB. Kscreenshot does not operate a cloud service that receives your screenshots or browsing content.

Some lightweight preferences may be stored with Chrome synchronized storage. If Chrome Sync is enabled, Google Chrome may synchronize those preferences according to your Chrome account and sync settings. Kscreenshot does not independently transmit those settings to a Kscreenshot server.

4. No sale, advertising, or unrelated use

  • Kscreenshot does not sell user data.
  • Kscreenshot does not transfer user data to third parties for advertising, profiling, creditworthiness, or lending purposes.
  • Kscreenshot does not use webpage or capture data for purposes unrelated to the extension's screenshot, editing, history, print, clipboard, and export functions.
  • Kscreenshot does not include advertising SDKs or analytics services that receive screenshot content.

5. Remote code

Kscreenshot does not download or execute remotely hosted JavaScript or WebAssembly. Executable code used by the extension is packaged with the extension.

6. Permissions

Kscreenshot requests Chrome permissions only to support user-facing features. For example, webpage access is used when you request a capture, the downloads permission is used to save files, clipboard access is used when you choose Copy to clipboard, and the Chrome debugging protocol is used for advanced full-page capture and searchable webpage PDF generation.

7. Data retention and deletion

You can remove local capture history from Kscreenshot's History page. You can also remove all extension-local data by uninstalling the extension or clearing the extension's storage data in Chrome. Files already downloaded remain in the location you selected and must be deleted separately by you.

8. Children's privacy

Kscreenshot is a general-purpose productivity tool and is not designed to knowingly collect personal information from children.

9. Changes to this policy

If Kscreenshot's data practices materially change, this policy will be updated and the “Last updated” date above will be revised.

10. Contact

For privacy or support questions, contact kemen.guo@gmail.com.

简体中文

Kscreenshot 是一款用于用户主动发起的网页截图、图片编辑、本地截图历史以及图片/PDF 导出的 Chrome 扩展。本隐私政策说明扩展会处理哪些信息、处理目的、数据存储位置以及用户如何删除相关数据。

1. Kscreenshot 会处理的信息

  • 网站内容：为了生成截图或 PDF 所必需的网页可见内容，例如文字、图片、页面布局、链接以及页面渲染结果。
  • 网页元数据：您主动截图页面的标题和 URL。这些信息可能用于本地历史记录、文件名、PDF 元数据、页眉或页脚。
  • 用户生成的截图数据：截图、编辑后的图片、标注、PDF 以及相关的本地历史记录。
  • 扩展设置：例如界面语言、图片格式、质量、文件名前缀、PDF 页面设置以及截图完成后的默认操作。

2. 信息的使用方式

Kscreenshot 仅将上述信息用于提供核心功能，包括网页截图、区域或元素选择、截图编辑、本地历史记录、复制到剪贴板、打印以及图片/PDF 导出。

3. 本地存储与 Chrome 同步

截图历史和截图文件保存在浏览器本地的扩展存储中，例如 IndexedDB。Kscreenshot 不运营接收您的截图或浏览内容的云端服务器。

部分轻量设置可能使用 Chrome 的同步存储。如果您的浏览器启用了 Chrome Sync，Google Chrome 可能按照您的 Chrome 账号与同步设置同步这些偏好。Kscreenshot 不会自行把这些设置发送到 Kscreenshot 服务器。

4. 不出售、不用于广告或无关用途

  • Kscreenshot 不出售用户数据。
  • Kscreenshot 不会为了广告、用户画像、信用评估或贷款目的向第三方传输用户数据。
  • Kscreenshot 不会将网页内容或截图数据用于与截图、编辑、历史、打印、剪贴板和导出功能无关的目的。
  • Kscreenshot 不包含用于接收截图内容的广告 SDK 或分析服务。

5. 远程代码

Kscreenshot 不下载或执行远程托管的 JavaScript 或 WebAssembly。扩展运行所需的可执行代码均随扩展一同打包。

6. Chrome 权限

Kscreenshot 申请的 Chrome 权限仅用于面向用户的功能。例如，网页访问权限只在您发起截图操作时用于捕获页面；downloads 权限用于保存文件；剪贴板权限用于“复制到剪贴板”；Chrome 调试协议用于高级整页截图和可搜索网页 PDF。

7. 数据保留与删除

您可以在 Kscreenshot 的“历史记录”页面删除本地截图历史。您也可以卸载扩展，或在 Chrome 中清除扩展存储数据，以删除扩展保存在本地的数据。已经下载到电脑上的文件保存在您选择的位置，需要由您自行删除。

8. 儿童隐私

Kscreenshot 是通用生产力工具，并非为了主动收集儿童个人信息而设计。

9. 隐私政策更新

如果 Kscreenshot 的数据处理方式发生重大变化，本政策会同步更新，并修改页面顶部的“最后更新”日期。

10. 联系方式

如有隐私或支持问题，请联系：kemen.guo@gmail.com。
